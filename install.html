Chapter 1 — Install

Secure Installation

This guide is safe-by-default. The recommended flow is: isolate → download → inspect → install → audit → lock down.

Don’t default to “curl | bash”. If you use a one-liner, treat it as a “fast path” and follow it immediately with an audit + lockdown.
Recommended (Safer) Fast Path
What you’ll accomplish
  • ✓ Install OpenClaw without risky shortcuts
  • ✓ Verify what you installed (audit first)
  • ✓ Prepare for Secure Setup (localhost + tokens + limits)
Quick sanity check
openclaw --version
openclaw audit

Step 0 — Choose a safe place to run it

🧰

Option A: Dedicated machine

Best for peace of mind. Use an old laptop, mini PC, or a spare desktop profile that has nothing important on it.

Why: if something goes wrong (malicious plugin, bad config, prompt injection), you’re not risking your main device.

🧊

Option B: Isolated VM

Great if you want a reset button. Run it in a VM (Virtual Machine) so you can wipe and start over.

Why: isolation is the single biggest safety multiplier. This is also the core pattern the NonBioS guide pushes. :contentReference[oaicite:1]{index=1}

🧯

Option C: Your personal machine

Not recommended, but if you do: use a separate user account and keep it locked to localhost.

If you’re just “trying it”, isolation/limits are the safer default.

Step 1 — Recommended install (safer)

Use the download links below (hosted on this site) so you aren’t pulling scripts from random URLs. Then do a quick review and run locally.

⬇️

Download installers

These links work once you add the files in Step 1a.

Download install.sh Download install.ps1
Pro tip: Next iteration: add checksums (SHA256) so people can verify downloads.
🍎

macOS / Linux

  1. Download installer to a file
  2. Quick review the first part of the script
  3. Run locally
curl -fsSL https://YOUR-NETLIFY-SITE.netlify.app/downloads/install.sh -o install.sh
chmod +x install.sh
sed -n '1,140p' install.sh
./install.sh

Replace YOUR-NETLIFY-SITE after deploy (or leave it and use the button download).

🪟

Windows (PowerShell)

  1. Download to a file
  2. Inspect the top of the script
  3. Run it
iwr -useb https://YOUR-NETLIFY-SITE.netlify.app/downloads/install.ps1 -OutFile install.ps1
Get-Content .\install.ps1 -TotalCount 140
powershell -ExecutionPolicy Bypass -File .\install.ps1
After installation: do not skip the audit. It catches misconfigurations early.

Step 2 — Verify + audit

✅

Verify version

openclaw --version

Confirms OpenClaw is installed and callable.

🛡️

Run security audit

openclaw audit

Treat warnings as “stop and fix” before you connect integrations or expose anything publicly.

🔒

Next: lock it down

Now go to Secure Setup: localhost-only dashboard, strong tokens, least privilege, and (if applicable) spending limits.

Continue to Secure Setup If you’re stuck

Fast path (less safe)

If you’re going to use one-liners, label them honestly as “less safe” and always follow with audit + lockdown.

⚡

macOS / Linux

curl -fsSL https://YOUR-NETLIFY-SITE.netlify.app/downloads/install.sh | bash
openclaw audit

Better: download first and inspect. This is here for convenience only.

⚡

Windows (PowerShell)

iwr -useb https://YOUR-NETLIFY-SITE.netlify.app/downloads/install.ps1 | iex
openclaw audit
🧾

Wallet safety (if using paid APIs)

If OpenClaw is connected to a paid LLM API, set a low daily/weekly spending limit while testing.

This is one of the most practical “safety defaults” highlighted in the NonBioS write-up. :contentReference[oaicite:2]{index=2}
