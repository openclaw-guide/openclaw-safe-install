Secure Installation

This page is designed to keep you safe by default. The recommended path is: download → inspect → run.

Important: Avoid running unknown remote scripts directly (example: curl ... | bash). If you use a one-liner, treat it as a “fast path,” not the default.
Step 0

Before You Start

Choose where you’ll run OpenClaw

Personal machine is fine to start. If this is for work/production, use a dedicated box or VM.

Keep it private by default

Plan to bind dashboards to localhost until you intentionally open access.

Decide your safety defaults

Strong token, minimal permissions, and a spending limit (if applicable).
Step 1

Recommended Install (Safer)

Download the installer to a file, quickly review it, then run it locally.

macOS / Linux

Download → inspect → run.
curl -fsSL https://YOUR-DOMAIN/downloads/install.sh --output install.sh
chmod +x install.sh
sed -n '1,120p' install.sh   # quick glance at the top
./install.sh

Windows (PowerShell)

Download → inspect → run.
iwr -useb https://YOUR-DOMAIN/downloads/install.ps1 -OutFile install.ps1
Get-Content .\install.ps1 -TotalCount 120
powershell -ExecutionPolicy Bypass -File .\install.ps1

Downloads

These links will work once you add the files into your site (see note below).
Download install.sh Download install.ps1
Optional: add checksums/signatures later for higher trust.
Step 2

Verify It’s Running

Run a security audit

This should be the first thing after install.
openclaw audit

Confirm version

Sanity check you’re on what you expect.
openclaw --version

Next: lock down access

Go to Secure Setup and keep dashboards local-only until you’re ready.
Go to Secure Setup Troubleshooting
Optional

Fast Install (Less Safe)

If you insist on a one-liner, keep it clearly labeled as less safe.

# macOS / Linux (less safe)
curl -fsSL https://YOUR-DOMAIN/downloads/install.sh | bash
# Windows PowerShell (less safe)
iwr -useb https://YOUR-DOMAIN/downloads/install.ps1 | iex
If you use these, at least do: openclaw audit immediately after.
